# Contributor guidance

Read PROJECT_OVERVIEW.md before editing and update it alongside meaningful
changes: implementation, file map, validation, limitations and ordered next actions.
The Mac controls an unlocked physical iPhone; blank-pad control is the default.
Screen viewing is optional. Preserve third-party notices and never commit private
device/signing data. Do not claim real-device support from builds/unit tests.
Run docs/DEVICE_TESTING.md before a stable release.
